# Decisiones de implementación — landing v1.0

Registro de diferencias entre las imágenes de `assets/` y la UI. Las imágenes no se editaron.

| ID | Decisión |
|---|---|
| OBS-01 | Paso a paso en móvil: texto arriba y preview abajo. No se copia el layout interno en dos columnas del PNG. |
| OBS-02 | «Tus ventas a la vista» no incluye gráfica de barras. Solo total, conteo y la leyenda «Ejemplo ilustrativo». |
| OBS-03 | Footer móvil con 48 px superiores (`pt-12`), sin el vacío grande del PNG. |
| OBS-05 | Casos de uso usan el copy largo de §6.5 / Anexo B, no el texto condensado de las imágenes. |
| TR-04 | El paso 02 no dibuja un código QR. El PNG muestra un glifo; un QR de demostración podría parecer cobrable. |
| PEND-01 | «Contactar al equipo» es un botón con `aria-disabled` y el texto visible «El canal de contacto todavía no está publicado.» No hay correo, WhatsApp ni formulario inventados. |
| PEND-02 | «Privacidad» se muestra como texto, no como enlace, hasta tener la política real. |
